- **事后核对一次都没有运行。** 9 个回合的核对记录全空：Codex 靠实时确认，Claude Code 靠回合正常结束。
- **“送达不明”没有出现**，包括刚发出就停止的那一回合。
- **准备耗时**（受理到派发）：首次切到 Codex 约 4.5 秒（启动 Codex），其余 0.3–0.7 秒。

## 费用与失败的尝试

真实提示共 19 次：基本一趟 3 次；长走查三趟 1、6、9 次。前两趟长走查停在脚本自己的缺陷上（一次读事件超过 Store 的 100 条上限），不是接力的问题，如实记在这里。Claude Code 自报的单回合用量约 3.1–3.3 万 token（绝大部分是缓存的系统提示），Codex 约 3.5–5.3 万；没有回合接近 15 万 token 或 5 分钟。
