## 审批条件的落实

1. **承载不变量的测试原样通过。** `pnpm test` 中的数据层与对话状态测试没有修改断言。
2. **许可证、体积。** 见“范围”。
3. **字体给用户的选项。** 见文末“给用户的选项”。
4. **新交互的条件。**
   - 数字键只绑定一次性选项：`lastingOption` 把 id 或名称含 always、session、始终、会话等的选项排除，只能点击；焦点在输入框时数字键照常输入（G054-FR8 测试：Allow always 没有编号，按 2 选中 Deny，输入框中按 1 只输入文字）。
   - 折叠摘要始终写出失败与未完成数量（`toolSummary`，G054-FR7 单元测试）。
   - 契约文案原样保留，由原有浏览器测试断言：已取消的原因（ADR-036）、期限来源与剩余时间（ADR-035）、排队与等名额（ADR-036）、原生命令沿用提示（ADR-028）、未经验证的版本（ADR-038）、恢复命令与两条提示（ADR-039）、诊断首行（ADR-037）、登录 shell 面板（ADR-040）。
   - 减少动效时动画与过渡不超过 1 毫秒（选择器、回复、命令面板）；倒计时有朗读区域，按“不到 1 分钟、30 秒、10 秒”分级播报，不逐秒打断；明暗两套都有浏览器测试（G054-FR6，深色下三页在 390 与 320 像素无横向滚动）；浏览器存储仍不含密钥与私有路径（首个浏览器测试的断言未改）。
5. **暂存下一条消息。** 写入该对话的草稿存储（与草稿同一机制：标签页内保存，重新载入后恢复）；只有暂存它的标签页会发出；三个前提缺一不可（本轮 completed、对话可接收、选择没有改变），否则放回输入框并说明原因；重新载入后放回输入框，不发出。G054-FR4 测试覆盖：正常发出一次、撤回、停止后放回、重新载入后放回、改选模型后放回。
   - 与审批意见的一处差异：草稿使用 `sessionStorage`，所以“关闭标签页”后暂存内容和草稿一样不保留（浏览器的“重新打开关闭的标签页”可以恢复）。保留在 `localStorage` 会被其他标签页看到，与“只由暂存它的标签页发出”冲突。
6. **部署。** 见下文“4317 部署”。

## 真实链路（开发实例）

2026-10-12 18:41–18:43，开发实例（端口 4327，独立数据目录，工作区为临时目录），真实 Claude Code 2.1.296（接入口 claude-agent-acp 0.89.1），本机登录，模式选 Manual（每次编辑前询问）。
