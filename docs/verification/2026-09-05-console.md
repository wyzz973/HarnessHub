## 边界

目前为本机单用户控制台，未验证 Windows 浏览器/Worker，也不代表远端多用户生产部署验收。DAG 按拓扑串行执行，规划审批不自动允许工具请求；部分引擎不会发起公共审批，不能宣称完整 OS 沙箱。自动选路是可解释的启发式，并非任务质量最优保证；执行结束和正确评分仍分开。

观测展示完整字段和来源/缺口，但不是账单对账：无可靠数据仍保持未知。跨引擎无损上下文迁移、所有独立依赖包版本穷尽采集、自动失败重试及大型数据 SQL 聚合不在本轮已验证范围。
