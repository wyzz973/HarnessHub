# 设计语言 2.0 实现验证记录（2026-11-01 起）

状态：代码完成，测试通过，主代理已逐项验收；**待用户验收**。真实 Harness 对话尚未在开发实例上做（部署到 4317 前要做）。只做 macOS，Windows 与 Linux 不在范围。

决定见 [ADR-054](../decisions/0054-design-language-2.md)，其“补充”记录集成时审批代理裁定的 A–R 各项。切片 `design-language-2`，用例 G054-DL1 至 G054-DL10。

## 来源与环境

- **设计稿：** Claude Design 画布第 20 版（私有）：https://claude.ai/artifact/H7XPvTZ31cJweAzsZGQn94
- **画板：** 共 11 块：设计方向、设计基础、首页、侧栏、对话（浅色与深色）、Agent、能力、动效、图标、交互。
- **代码：** 在独立 worktree 中实现，分支 `cc/design-language-2`，起点 `07a0825`。
  - 先由基础组完成令牌、字体、动效与通用组件。
  - 再由外壳、对话回合、对话、Agent、能力五组并行开发，每组由另一名成员复核。
  - 合并后又做了四批集成修补，每批也是一人开发、一人复核。
  - 正在运行的 4317 实例与主目录没有改动，没有推送。

## 验收方法

- **对照截图：** 每条都把画板截图与浏览器测试截图（`artifacts/chat-v3/`，git 忽略）并排对照。
  - 浏览器测试生成截图共 300 多张，其中 G054-DL10 覆盖各页面在 1440、390、320 宽度和浅色、深色下的样子。
  - 并排对照图是验收时临时生成的，不入库。
- **对照数值：** 动效逐条比对动效画板的数值表与 `web/src/styles.css`、`web/src/ui/motion.tsx` 的实现；运行时数值由各用例断言。
- **核对事实：** 只显示网关已有的事实（ADR-054 第 6 节）。网关没有提供的，记为“事实所限”，不估算。
- **结果的写法：**
  - “通过”指与画板一致、或差异有记录在案的依据；
  - “部分”指受网关事实所限，缺的部分列在“后续工作”。

### 执行的命令

2026-11-02 在集成分支 `cc/design-language-2` 上执行（提交 `b82c457`，五批集成修补全部合并后）：

- `pnpm check`：通过。设计检查通过，边界检查没有违例（3 个登记的例外），工具测试 63 项通过。
- `pnpm test`：单元、集成与协议测试 873/873 通过（改动前的基线为 857）。
- `pnpm test:web`：浏览器测试 70/70 通过，用时约 391 秒（改动前的基线为 47）。

每项新检查都在撤掉对应修改时跑过一次，确认它会失败，再恢复。

### 有意的差异

- **完成通知不写对话标题。** 沿用 ADR-035，偏离交互画板的示例（补充 A）。
- **审批等待时，过程行写“想运行 …”。** 对话画板示例里写的是“正在运行 …”，那条命令其实还没获准，这样写是错的（补充 J）。
- **对话框圆角取 ADR 阶梯的 14。** 能力画板的写入预览画的是 18。
- **详情面板的改动计数是改动次数。** 画板按文件计。
- **界面上把这个概念叫“Harness”。** 画板写的是“Agent”；用户 2026-11-02 决定用“Harness”，推翻补充 Q。

### 后续工作（网关）

- **会话摘要：** 给出上次回合的结果与更新时间，侧栏就能标出页面没见过的失败，并显示相对时间。
- **其他对话的回合结束事件：** 有了它，其他对话做完、失败时也能通知。
- **每个 Agent 的模型数与能力数汇总：** Agent 卡片要用。
- **审批请求带上工作目录和对应的工具 id。** 有了工具 id，“想运行 …”就能直接对准请求的那一步。
- **工作区文件搜索：** @ 引用工作区里的文件要用。
- **按下缩小（动效 #31）：** 按钮按下时缩到 0.97，在按钮最边缘约 1 像素处按下，松开时可能已落在按钮外，这一下不算。审批停靠的决定按钮已经补了命中层；收件箱与审批卡片的一次性选项、提问卡片等其他按钮还没有补。
- **扩展面板选技能时遇到半截的 / 命令：** 例如草稿是“/rev”，选技能后会变成“/skill:x /rev”。要不要改成替换半截命令，待定。
- **Provider 管理的用词：** “Provider 配置”“选择 Provider”等仍写 Provider。这一块是后置功能，生产页面没有开启。

- **真实 Harness 对话：** 还没做，所有证据都来自仓库的夹具。部署到 4317 前要在开发实例上做一次。
