# 公共上下文与交接材料

状态：proposed。Continuity 拥有派生材料与验证，不拥有原生 Harness 的内部状态。

## ContextManifest

不可变 manifest 包含 sessionId、throughSeq、工作目标与约束、公共消息引用、已完成/待办、用户批准的决定、工作区快照/修改摘要、产物 ID/hash、工具方案引用、来源指纹、构建策略版本、内容长度与预算估计来源。

正文可以由公开文本和可读工作记录组成，不复制旧 Harness 的原生工具调用 ID、隐藏状态、未经声明的内部材料或秘密。文件/工具输出视为不可信数据，不能把其中的指令提升到系统/用户命令。

## 取材与边界

第一版优先确定性的公开历史/事实渲染，按能力与显式预算决定能否交接。超限明确 CONTEXT_TOO_LARGE；不静默只取最近 N 条。需要摘要时另建派生记录，保留原始来源、未包含内容与水位，摘要不可覆写原始消息。

字节限制和模型 token 估计分别记录。能力目录中的窗口是声明/元数据，不是实际 Provider 已接受证明；上下文构建失败在启动前结束。

## 切换与返回

旧执行停止/结算后固定 throughSeq 与 workspace fingerprint，再生成材料并校验目标 Harness 的 import 能力。返回 Harness A 时，只能复用已经同步到该水位的绑定，否则新建或以显式补充方式更新。

期间有新公共消息到达时，它们进入有序待处理队列；manifest 不偷偷吸收新输入。外部程序修改工作区时重新核验 fingerprint 或明确冲突；网关租约不能阻止所有外部写入。

## 接续等级

native_resume：同后端且恢复证据匹配；public_context_rehydrate：重新准备原生上下文，依靠公共材料接续；blocked：目标能力/预算或当前结果不满足。

等级、缺失材料和版本对用户可见。UI 可以保持同一个对话视图，但不能因此声称原生内部推理和状态被无损迁移。
