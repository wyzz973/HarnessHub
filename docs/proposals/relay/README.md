# 接力系统重新设计（2026-11-02 至 11-03）

用户在 2026-11-02 晚要求重新设计接力系统与上下文调度，并经过多轮小组讨论迭代，次日早上验收。本目录是整个设计过程的记录。

- **结论**：[relay-architecture.md](relay-architecture.md)，即终稿。
- **决定**：[ADR-055](../../decisions/0055-relay-and-context-scheduling.md)，状态 proposed。
- **契约**：契约、不变量与实施计划都按终稿更新，状态同样是 proposed。

本设计未实现，也未经真机验证。在用户验收之前，不改 Session 运行时，也不改业务库格式。

## 怎么读

1. 先读终稿开头的“状态与验收”一节：哪些地方需要你拍板，哪些数字是实测，哪些是推算。
2. 再读终稿第 0 节摘要、第 5.6 节交接单样例（目标 Harness 实际看到的全文）、第 16 节场景走查。
3. 想知道某个决定从哪里来，看第 18 节的要求落实表与第 19 节的否决理由，再顺着链接回到各轮记录。
