# ADR-008：先做本机核心链路，按小切片推进

日期：2026-10-09。状态：accepted，范围来自用户本轮明确优先级；不表示旧的七项架构建议已自动采纳。

## 决定

先在当前宿主跑通核心功能，不以跨平台发布、多发行版兼容矩阵或完整未来架构冻结阻塞可独立验证的只读功能。先交付 catalog-discovery：本机可执行入口检测、控制配方、依赖解析和可扩展描述文件。

完整规划保留为后续地图。小切片在 plan/slices.json 明确已冻结范围、唯一允许路径、所属任务与验证；只有该范围可以实现，Session/执行/切换的全局门禁仍关闭。

## 保留的工程要求

领域与 I/O 分离、unknown 输入校验、显式错误、无静默替换、有界资源、测试和证据继续有效。涉及持久 Session、原生执行、权限与切换时，先关闭相应契约和失败窗口。

检测到可执行入口与适配器候选不表示已通过协议或模型验证。检测阶段不启动被发现程序、不探测登录、不下载包、不修改用户文件。

## 延后

Windows 原生 Helper、签名/打包/发布、多 Harness 发行版矩阵、完整遥测平台和学习型最优路由。记录实际使用版本供诊断即可，不建立首版多版本支持承诺。

## 验收

编译后的只读 CLI 能扫描，数据配方可扩展，误检测/缺依赖/覆盖路径等有测试；其他未批准模块不能因为这一切片而进入实现。设计检查器同时加入合法切片和越界源码拒绝样例。
