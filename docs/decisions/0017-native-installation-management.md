# ADR-017：管理本机安装渠道与原生接入

状态：accepted，2026-10-11。用户要求在OpenClaw修复后继续完成本机安装/升级与接入；使用原安装、原配置、原登录，Provider统一管理后置。

## 范围与决定

- 生产安装操作改为本机渠道：已有Homebrew/npm/uv安装沿用原渠道和路径；开发目录链接不得升级成另一个包。未安装的npm/Python控制适配器安装到现有本机包管理器的标准位置；审核归档安装到用户级程序目录并发布终端入口。旧私有记录保留历史，不能成为生产安装的目标。
- 操作先收敛为冻结计划：渠道、原入口、包身份/前版本/指纹、目标版本、安装位置。不能把最新npm版本当Homebrew目标，也不能降级现有更高版本。取消、失败、实际本机版本与配置保护分别记录；派发后未知不自动重跑或回滚。
- 在持久管理任务中执行计划，保持正式HTTP、SQLite、幂等、CAS、日志、取消和关闭。原生任务的回执不会写入旧private default指针。新增持久字段/表兼容读取旧数据，管理库追加迁移，业务会话历史不清除。
- 原生程序有跨入口共享的使用/维护锁。控制连接持有读锁直到关闭，安装升级持有维护锁；发现活动本机进程时拒绝原地升级，不杀其他任务（2026-10-12 起由 [ADR-043](0043-upgrade-with-running-programs.md) 取代：先列出使用安装的程序并征得同意，按产品自己的方式重启后台服务，其他程序继续用旧版本）。崩溃/已派发后不确定结果保留待核实标记，禁止假造正常安装。
- 本轮以macOS为真实宿主。包管理器/原生更新器在明确拒绝写入用户模型、认证配置及shell配置的沙箱中运行，另核对配置摘要；缺少已验证的保护时能力明确不可用，不以较弱路径绕过用户约束。官方更新器需要配置迁移或改变登录时明确失败，不自动doctor修复。
- 真实本机控制适配器连接原CLI。Claude ACP必须指向已安装的Claude Code可执行文件并复用登录，不能悄悄使用捆绑CLI。Pi为开发目录时保留原入口；原生协议/适配器支持按本机版本核实。其余已安装Harness先使用已配置模型，DeepSeek测试只在Harness原生支持的配置边界内进行，不能通过Hub Provider伪造兼容。
- 所有渠道/产品的实际能力分开显示。未审核的原生升级、登录缺失、旧CLI没有ACP等不作为已接通；界面提供准确的原因和修复入口。
- Pi直接连接本机CLI的RPC，不安装另一个Pi或复制SDK。模型选择使用单次启动参数；其set_model会写全局默认，因此不调用。接收agent_end中的后端结果并等待agent_settled，提示受理、运行静止与进程清理分开验证。当前协议依据本机0.85.1源码；不支持这一静止回执的旧版本明确超时失败。
- Homebrew标准前缀在本机不能嵌套macOS配置保护沙箱，原生升级目前明确不可用；不禁用Homebrew安全机制、不修改它的源码或把未知回执当成功。版本检查和本机原程序接入仍可用。

## 来源与验收

本机源：Codex Homebrew cask0.160.0（渠道0.162.0）；OpenCode anomalyco/tap/opencode1.18.35；Gemini为Homebrew目录而实际CLI版本高于渠道；Claude Code npm安装及现有Max登录；OpenClaw npm2026.3.23-2及现有DeepSeek；Pi指向用户开发目录。读取npm/Homebrew/uv原生元数据与官方文档，不据此自动修改安装。

Claude ACP源码固定4e1fc1e8df2b9af3b1b2d6880ba90c5862283ba8，读取CLAUDE_CODE_EXECUTABLE覆盖机制。源代码及第三方指令仅作为参考。实际验收须包含正式HTTP/数据库/进程、配置写入拒绝反例、并发维护、原安装变化/未知恢复、真实本机安装或升级及真实多Harness回复；合成外部包管理器不得冒充用户实际程序升级。
