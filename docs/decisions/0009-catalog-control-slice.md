# ADR-009：扩展目录与受控原生控制切片

日期：2026-10-09。状态：accepted。授权依据：用户认可发现与适配方案并要求开始实现。

本次冻结 E01–E07 的本机范围：目录 v2、固定 ACP 稳定快照、本地安装枚举、已有包装器解析，以及 ACP/Codex 受控控制连接。正式 CLI 提供只读 discover/catalog、主动 probe 与一次文本调用 run。主动调用选定具体 Harness/控制入口，不自动换目标；没有声明/实现的客户端工具能力不启用。

默认 discover 使用 v2，--legacy 输出已有 v1 报告；v1 描述文件迁移为 v2 定义，不改变其校验和覆盖语义。CLI 默认只读扫描不启动程序、不下载依赖、不读取登录凭据。协议 Driver 一次连接一个原生对话、一个 active run；原生身份不冒充公共 Session。

全量未来 Gateway、持久公共 Session、自动路由、Provider 转发与跨 Harness 切换仍按后续切片实现。本切片不能声称整个统一网关已完成。平台/发布不成为本机控制面前置。

所有新增源码在 plan/slices.json 明列；任务唯一 owner 仍按 plan/tasks.json 管理。公开报告不得将目录条目数当成执行支持数。输入、目录、帧、诊断、请求和关闭均有上限；未知协议结果不重试，运行失败不得被另一个安装掩盖。

契约与测试范围见[目录与控制契约](../contracts/catalog-control.md)。
