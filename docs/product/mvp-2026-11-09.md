# 最小可用版本：功能清单（2026-11-09）

日期：2026-11-09。用途：给第一批用户与宣传用，列出这一版能做什么、每一条的证据到哪一级、哪些还不能说。证据等级分开写：**已实现**（代码已提交）、**合成测试**（假 Harness 或本地确定性模型服务）、**真机**（本机真实安装的 Harness 与真实模型）。只支持 macOS，从源码运行，界面只有中文。

## 一句话

在你的 Mac 上，用一个对话驱动你已经装好、登录好的 Claude Code、Codex、OpenCode、Hermes Agent、DeepSeek Harness 和 OpenClaw；换一家接着做时，HarnessHub 把前面发生的事整理成交接单交给它。

## 给谁

已经在 Mac 上按官网方式装好、登录好至少一个上述 Harness，并且经常在几家之间来回切换的开发者。

## 功能

### 1. 一个对话，用任何一家

- 公共对话属于 HarnessHub，不属于某一家；两条消息之间就能换 Harness、模型或思考强度。
- 每一家用它自己的安装、登录和模型；HarnessHub 不建空配置目录，也不改你的全局模型设置。
- 回复流式显示，刷新不丢，也不会重复发送；结果未知的执行不会被自动重跑。
- 可以接续某一家自己的原生会话，也可以从任一条回复分支。

证据：已实现；真机按功能记录在[能力矩阵](../verification/native-capability-matrix.md)与各家最新版的重验记录里。

### 2. 接力：换一家，接着做

- **新加入的一家收到交接单。** 内容是：用户原话（开场请求与最近的消息逐字保留）、状态与风险、每一家做过什么（读写了哪些文件、跑了哪些命令、退出码、回复）、文件改动表，以及“未包含”一节，写明省略了什么、隐去了几处疑似密钥。
- **回到原来那一家，只补增量。** 它在自己的原生会话里继续，只收到它离开期间别人做的事。
- **只用一家时零注入。** 没有欠交的历史就原样发送，和直接用那一家一样。
- **长历史不失败。** 按预算确定性折叠，目标是不超过 8,000 token、也不超过上下文窗口的 5%，并在交接单里写明折叠和省略；不会因为历史太长而拒绝发送。窗口在 32k 以下时，光框架就会超出这个目标。
- **交接单不当指令。** 历史放在带标记的引用区里，附阅读约定：只有末尾“用户现在的指令”是要做的事，过去的批准不继承。
- **隐去密钥。** 交接单生成时，按已知的密钥值与常见格式隐去，读凭据文件的命令不附输出。这是尽力而为：格式未知的秘密仍可能被带出。
- **可追溯。** 每份交接单的策略版本、ID、发出全文的 sha256 与来源区间都写进事件；正文不进日志。

证据：已实现，合成测试通过（[验证记录](../verification/relay-mvp-2026-11-09.md)）；真机：两对冒烟，数字只存在于前一家的回复里，后一家答对只能靠交接内容。OpenCode → DeepSeek Harness → OpenCode 全程通过：DeepSeek Harness 只凭交接单答对了 OpenCode 想的数，回到 OpenCode 后它从增量得知了 DeepSeek Harness 的回答。Claude Code → Codex → Claude Code：Codex 只凭交接单答对；回到 Claude Code（haiku）时，增量里写着 Codex 的回答，它却答成了自己的数。设计见 [ADR-055](../decisions/0055-relay-and-context-scheduling.md)。

### 3. 每一家的原生能力原样接出

- 模型、思考强度、模式与 `/` 命令都从各家读取。
- 审批停在输入框的位置（允许一次或拒绝），以及原生的提问表单。
- 计划、带差异的工具输入与输出、子 Agent、用量。
- 文件、图片和音频按各家自己的输入方式发送；`/compact` 与 `/export` 交给有这些命令的那一家自己执行。

证据：已实现；完成度逐家逐项见[能力矩阵](../verification/native-capability-matrix.md)：Claude Code 22 项、Codex 20、OpenCode 16、Hermes Agent 16、DeepSeek Harness 13、OpenClaw 10（共 27 项）。

### 4. 照看你 Mac 上的这些 Harness

- 只认官网渠道的安装（npm、Homebrew、厂商脚本、uv），多份安装都列出，并标出当前用的是哪一份。
- 安装、升级、卸载之前，先预览每一条命令；升级后按产品自己的方式重启它的后台服务，并确认它重新运行。
- 一个页面统一查看和开关各家的技能、MCP 服务器、指令、命令、Hooks 与插件。只改用户级配置，写入前先预览差异。

证据：已实现，真机验收记录见[文档索引](../README.md)里的管理与能力配置各条。

### 5. 本地、可恢复、够快

- 页面只在 `127.0.0.1` 提供，用一次性链接登录；数据在你自己的 SQLite 里。
- 事实先提交再显示：刷新会如实重放发生过的事。
- 长对话也快：快照接近 8 MiB 时，从发送到交给 Harness 的 p95 是 281.7 ms。这是参考机上只计 Hub 自身工作的测量，见 [G075 验证记录](../verification/relay-g075-2026-11-09.md)。

## 这一版还没有的

- **WorkBuddy 还没接入**；Cursor、Gemini CLI 与 Pi 已冻结在焦点之外。
- **接力的送达证据还没落库**（v13）。v12 上按推进规则判断是否需要补交，“只发这条消息”只有接口，没有界面按钮；交接单的折叠与省略在界面上看不到。
- **常驻原生宿主还没做**（[ADR-056](../decisions/0056-native-hosts-and-sessions.md) 已接受，等 v13、v14）。
- **跨厂商的交接质量没有系统评测**：真机只做了数字接力这类冒烟。一次冒烟里，回到自己会话的 Claude Code（haiku）答错了一份内容正确的增量，原因还没有确认；各家模型读交接单的实际效果，要用真实任务再看。
- 只支持 macOS（Windows 与 Linux 不再计划）；没有安装包；界面只有中文；统一管理模型 Provider 以后再做；自动选择 Harness 不做。

## 对外介绍时

可以说：
- 一个对话用上你 Mac 上已经装好的六家编码 Harness，各用各的登录和模型。
- 换一家接着做，它会收到一份交接单：你的原话、前面谁做了什么、改了哪些文件；回到原来那家，只补它没看到的部分。
- 只用一家时，HarnessHub 不往对话里加任何东西。
- 在真机上，Codex 和 DeepSeek Harness 只凭交接单，就答出了前一家回复里的内容。
- 本机运行，只监听 127.0.0.1。

不要说：
- 原生会话、思考过程或内部状态被“无损迁移”：交接单只来自公开记录。
- 密钥“绝不会”外带：脱敏是尽力而为。
- 会自动选出最合适的 Harness。
- 支持 Windows、Linux 或 WorkBuddy。
- 宣传片里的五棒内容和数字是真实运行：它们是示意；把总结发到手机是 OpenClaw 自己的功能，没有经 HarnessHub 实测。
