# T3 Code 调研（2026-11-14）

用户要求全面学习 T3 Code（pingdotgg/t3code，MIT），据此优化 HarnessHub 的功能、体验和页面。这份是看到的事实和我们的取舍。实物用 `npx t3@latest` 在临时项目里跑（1440×900，浅色主题），源码读的是当天的 `main`（`d19467a5`）。

## 实物上看到的

**整体**。三栏：左侧栏 256 宽，中间对话，右侧面板可开可关（开时约 540 宽）。右侧面板关着时，对话右上角浮着一张“线程详情”卡。页头是面包屑“项目 / 线程标题”，右边三个布局开关（线程详情卡、终端抽屉、右侧面板）。线程标题由模型生成，很短（“Add Cart Total and Currency Formatting”），不是第一条消息。

**线程详情卡**（宽 278，圆角 16）。两段，段间一条发丝线，每行高 32、13 px 中等字重、左边一个图标、右边值或展开箭头：运行环境、“Open in Cursor”、“Add project script”；分支、“Commit”（没有提交时是“Publish repository”）、“Changes Uncommitted +12 −0”。

**时间线**。用户消息是右侧灰底气泡。进行中：一行“Working for 24s”加发丝线，下面是助手的话，以及一行一件的动作——“Tasks 0/3 · 当前这一步”（整份清单压成一行，可展开）、“Running ls”（文字带流光）。结束后：整段过程收成一行“Worked for 41s ›”，点开是夹着助手中间话的动作行（“Tasks 3/3”“Ran 4 commands and changed 3 files”、一条命令一行）；然后是最终回复；再下面一张**改动卡**：“3 changed files +12 −0”、全部展开或收起、“Open diff”，卡里是文件树（目录可收起，文件前有状态标记，右侧是等宽的增减行数）。

**改动面板**（右侧面板的一个标签页）。顶上是标签条（“Diff”、已打开的文件各一个标签、“+”）；下面一行工具：范围下拉（Changes / Uncommitted / Latest turn / 某一轮 / 某次提交）、基准分支、总增减行数、全部收起、堆叠或并排、折行、空白、文件树。正文是**每个文件一段**：展开箭头、状态标记（修改是方框里一个点，新建是方框里一个加号）、路径、右侧增减行数；点开就在下面显示差异，新增行浅绿底加左侧绿条。点文件名会把这个文件开成一个新标签。

**侧栏**。搜索、按项目筛选、加项目、新线程。线程行是一张小卡：项目徽标与名字、时间（now）、标题、Harness 图标；悬停出现“稍后提醒”和“✓ Settle”。底部有“Working n”“Settled n”两个可展开的分组：进行中的线程收在 Working 里，要你处理时回到顶上；Settle 是“这件事了结了”。右键菜单：置顶、了结、稍后提醒、重命名、重新生成标题、标为未读、按项目筛选、自动了结、复制、项目设置、归档、删除。

**输入框**。占位“Ask anything. @ files, $ skills, / commands”。右下是一个选择器“6 Astra Medium ⚡”，点开是三栏浮层：左边一列 Harness 图标（含收藏），中间搜索加模型列表（可收藏），右边“Reasoning”各档；底部一条“Standard | Fast”和权限档“Full access”。运行中发送键变成红色停止键。进行中再发消息可以排队或中途插话（设置里选默认，⌘ Enter 取反）。

**命令面板**（⌘K）。居中大浮层，背景模糊；“Actions”分组里每行一个图标、名称、右侧快捷键，有的带一行说明；底部一条按键提示（↑↓ Navigate、Enter Select、Esc Close）。

**设置**。大弹层：左边带图标的分组导航和搜索，右边每组一个标题、一张卡，卡里每行是“名称 + 一句说明 + 右侧控件”。有外观（配色、主题、对比度、聊天宽度、详情卡显示哪些行、字号）、聊天（发送键、排队还是插话、动作显示多少：全部 / 只隐藏成功的 / 只看最终回答）、快捷键（可改）等。

**颜色**（浅色）：底 `oklch(99.2% 0 0)`，字 `oklch(21% .006 286)`，次要字 `oklch(55.2% .016 286)`，边线 `oklch(92% .004 286)`，强调蓝 `oklch(48.8% .217 264)`，圆角基数 8 px。界面字 16 px 可调，等宽 13 px。

**它在机器上留下的**：`~/.t3/runtime`（约 351 MB）；每在一个新目录里跑 Codex，`~/.codex/config.toml` 多一段该目录的信任记录。

## 源码里读到的（三个子代理通读 `apps/web/src`，只读未运行）

**时间线**（`components/chat/MessagesTimeline*.ts(x)`、`TimelineWorkGroupRows.tsx`、`packages/client-runtime/src/work-log/presentation.ts`）
- 一轮结束后，最终回复之前的全部过程收在一行“Worked for 1m 3s ›”后面（右侧是时间）；留在外面的只有失败、还在进行的、通知、已回答的提问。被中途插话打断的过程另起一行“Continued for 8s”；用户停下的是“You stopped after 8s”。
- 进行中，一组动作只显示最新的一条（“Running pnpm”，动词有 Running / Ran / Failed / Declined / Stopped），上面一行是思考的第一句（最多四行）；什么都没有时是“Thinking”。流光是 2.2 秒一遍的渐变扫过，滚出屏幕就停。
- 一组动作的一句话小结：按类别“Ran N commands”“Changed N files”“Read N files”“Searched code N times”“Used N tools”，最多点名两类（命令、改动优先，其次读和搜），其余并成“and performed N other actions”。单独一个动作就显示它自己（命令原文、“Read foo.ts”）。
- 页头的计时直接改文字节点，不触发重渲染。用户长消息超过约 22rem 才折叠（“Show full message”）。消息的时间和操作（复制、从这里改、分叉）悬停才出现；时间写成“14:03”“yesterday at 14:03”。
- 压缩是一条居中的发丝线“Context compacted 180k → 40k tokens”。错误单独一行，红色图标，写明“Retrying provider (2/5)…”。
- 设置里可选动作显示多少：全部 / 隐藏成功的 / 全隐藏 / 只看最终回答。

**改动卡**（`chat/ChangedFilesTree.tsx`）
- 在最终回复下面：`rounded-lg bg-secondary`，头部“3 changed files +120 -4”，按钮是全部展开目录和“Open diff”（卡片窄时只剩图标）。树：目录在前、自然排序、只有一个子目录的链并成一行（`src/components/chat`）、默认收起、目录带合计；行高 28、等宽、文件名中间省略。点文件开它的差异。

**批准与提问**
- 批准在时间线里那个动作的位置上：请求内容放等宽块里，下面“Waiting for approval · Decline / Approve / More”。用户正在输入框里打字时到达的批准会被按住 1.5 秒，免得回车误答。
- 提问停靠在输入框上方：选项带 1–9 快捷键，单选选完 200 毫秒自动到下一题，发送键变成“Next / Submit answer”。

**输入框**（`ComposerPrimaryActions.tsx`、`ProviderModelPicker.tsx`）
- 发送键是 32 的圆钮。运行中且草稿为空：红色停止键，点了显示“Stopping…”最多 10 秒，停止后 500 毫秒内不让重复发送。运行中且有草稿：排队或插话的图标，按住 ⌘ 当场切换。排队的消息是对话末尾的虚线气泡，可“Send now”、改、删。
- `@` 文件、`/` 命令、`$` 技能的选择器是贴在输入框上方的抽屉。草稿按线程存本地。
- 模型选择器：左边一列 Harness，中间模型，右边思考档；选了模型不关，留在思考档上。

**侧栏**（`components/Sidebar.tsx`、`sidebar/*`、`settleAndAdvance.ts`）
- 按状态分，不按项目：置顶、活动（卡片，78 高，三行：项目与状态、标题、分支与改动数），底部三个可折叠的架子 Working / Snoozed / Settled（单行，36 高）。进行中的收在 Working 里，结束、失败或要你处理时回到活动的最上面。
- 状态位：“Working 24s”（蓝，每秒走）、“Approval”（琥珀）、“Input”、“Failed”（红）、“Done”（没看过的完成），否则是相对时间（now、5m、2h）。**悬停时操作按钮就换在这个位置上**（稍后提醒、✓ Settle），所以行不会抖。
- “退后”规则：不需要你管的行画得更淡（常规字重、标题 75% 不透明度，进行中的整行 70%）；要你处理的、没读的、失败的保持全对比度。
- Settle 之后跳到下一个没了结的线程；所有侧栏操作 5 秒内可用 ⌘Z 撤销，不弹确认框。
- 浅色下：侧栏底是 zinc-50，悬停更亮，选中是纯白加一圈发丝线，像一张垫高的纸。

**页头**：面包屑“项目 / 标题 ⌄”，双击标题就地改名；右边三个开关都带快捷键（⌘⇧B 详情卡、⌘J 终端、⌘⌥B 右侧面板）。

**右侧面板**（`rightPanelStore.ts`、`RightPanelTabs.tsx`）
- 默认宽 540，最小 360，最大视口的 70% 且给对话留 360；宽度、打开的标签、当前标签都按线程记住。拖动把手是左边缘一条 1 px 的线。窗口窄于 980 变成从右滑出的层。
- 一轮结束时主动打开改动页是个设置，默认关；用户动过面板就不再主动开。
- 文件差异按文件懒加载；头部吸顶；有“复制路径”。选中差异里的几行可以写评语，评语挂到下一条消息上。

**命令面板**：空查询显示操作和最近线程；输入后分组为建议、线程、项目、设置、消息里的命中；`>` 只看操作；按词首匹配、容许打错、按使用频率和最近度排序。

**快捷键**：⌘B 侧栏、⌘K 面板、⌘N 新线程、⌘F 线程内查找、⌘⇧[ 和 ⌘⇧] 上一个下一个线程、⌘1–9 跳到第几个、⌘⇧S 了结、⌘⇧P 置顶。提示气泡里都写着快捷键。

**动效**：面板动画默认 0 毫秒（即时），切换线程后的两帧内不放动画；侧栏行移动 150 毫秒；高度变化 200 毫秒；弹层 200 毫秒从 0.98 放大。

**通知**：别的线程完成、要输入、要批准、失败时，应用在前台就在右上角出一条提示（带“Open thread”），在后台就发系统通知；标签页图标变成带数字的红点。
