---
name: portable-review
description: Review explicitly selected local source changes and report evidence and remaining limitations.
---

Use this Skill when the user asks for a review of local source changes. Read the
selected files and the repository's own development rules. Apply the checklist in
`references/checklist.md`, resolving that path relative to this SKILL.md file.

Report actionable findings with file locations and observed effects. Distinguish
checks actually run from checks that still need execution. Keep the user's scope
and authorization as the governing instructions.
