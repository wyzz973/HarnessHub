# Local review checklist

- Identify the intended behavior and the smallest concrete example that demonstrates it.
- Check input validation, error propagation, cancellation and resource cleanup where relevant.
- Check that a changed persistent format or interface has matching consumers and documentation.
- Prefer existing meaningful tests. State which checks ran and what their results establish.
- Report unresolved risks separately from observed defects. Do not claim model or platform validation that did not run.
