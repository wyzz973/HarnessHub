# @harnesshub/cli

`hh` 命令中不属于守护进程的部分。[admin.ts](src/admin.ts) 是模型平面命令 `status`、`provider`、`credential`、`key`、`group` 与 `usage`：经 `@harnesshub/sdk` 调用运行中的守护进程，输出表格或 `--json`，退出码与秘密输入方式见 [模型平面 API 与 CLI](../../docs/model-plane-api.md)。[console.ts](src/console.ts) 是 `hh console`：以管理令牌向守护进程申请 60 秒内可用一次的登录码，打印 `<守护进程地址>/#login=<code>`（`--json` 输出 `{url, expiresAt}`），见 [控制台](../console/README.md)。[agents.ts](src/agents.ts) 是 `agents`、`wire`、`use`、`unwire` 与 `profile`；[tui.ts](src/tui.ts) 是 `hh tui`：终端界面（[tui/app.ts](src/tui/app.ts) 是屏幕与操作，[tui/terminal.ts](src/tui/terminal.ts) 是按键解码、列宽、样式与只重绘改变的行的屏幕，不依赖第三方库），同样只经 SDK 访问守护进程，见 [全局接线](../../docs/global-wiring.md#终端界面)。[cli.ts](src/cli.ts) 是 `rollout` 子命令：经 Gateway 的轨迹接口把已提交的事件流式导出为文件（[rollout/export.ts](src/rollout/export.ts)），拒绝覆盖已有文件。内容在 OSS-004 第 9 步从 `src/cli.ts` 与 `src/rollout` 迁入。按依赖图它只能依赖 `@harnesshub/core` 与 `@harnesshub/sdk`，通过 HTTP 而不是导入服务端包访问守护进程。编译后的入口是 `dist/src/cli.js`。
