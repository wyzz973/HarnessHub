# Name and Trademark Policy

This policy explains how the HarnessHub name may be used and how HarnessHub
refers to other projects' names. It is not legal advice and it does not change
the [MIT License](LICENSE): the license covers the code, this policy covers the
name.

## The name

- The project is called **HarnessHub**.
- The official command is `harnesshub`. `hh` is an optional short alias that is
  installed only when you run `harnesshub alias install`; system packages and
  package managers install only `harnesshub` by default, because `hh` is
  already used by other tools such as HSTR. Documentation that writes `hh`
  means the same command.
- The project's home is <https://github.com/wyzz973/HarnessHub>. The owner,
  [@wyzz973](https://github.com/wyzz973), holds the project's accounts and
  decides on uses of the name that need permission.
- HarnessHub has not applied for a registered trademark. This policy describes
  how we ask the name to be used so that users are not misled about what is
  official.

## Projects and companies we are not affiliated with

- **The `HarnessHub` organization on GitHub** (<https://github.com/HarnessHub>)
  is an unrelated project. Its `HarnessHub/HarnessHub` repository is a
  packaging standard for agent runtime environments with a command named
  `harness`. This project is not affiliated with it. Where package registry or
  container names could be confused, this project uses clearly distinct names.
- **Harness Inc.**, the software delivery platform company, is not affiliated
  with HarnessHub, and nothing in this project implies any relationship with
  it.

## Uses that do not need permission

- Describing compatibility truthfully, for example "works with HarnessHub" or
  "a plugin for HarnessHub".
- Redistributing unmodified official release artifacts.
- Referring to HarnessHub in articles, talks, comparisons, and documentation.
- Naming a community plugin `harnesshub-plugin-<name>`, provided it does not
  claim to be official.

## Uses that need the owner's permission

- Using the HarnessHub name for a modified distribution or fork.
- Implying that a product, service, or plugin is official or endorsed by the
  HarnessHub project.
- Using the HarnessHub name in the name of a commercial service.

If you fork HarnessHub and distribute a modified version without permission,
give it a different name and say clearly that it is based on HarnessHub. To
ask for permission, open a [Discussion](https://github.com/wyzz973/HarnessHub/discussions)
or contact the owner.

## Third-party names and trademarks

HarnessHub works with many coding agents and model providers. Names such as
Claude Code, Codex, Gemini CLI, and the names of model providers are
trademarks of their respective owners. HarnessHub uses them only to identify
the products it interoperates with (nominative use):

- HarnessHub does not use vendors' logos.
- HarnessHub is not affiliated with, sponsored by, or endorsed by any of these
  vendors unless a vendor states otherwise.
- Adapter documentation records only the configuration locations and formats
  needed for interoperability. Configuration samples are written by this
  project and are not copied from vendor documentation.
- Provider presets contain factual data only (endpoints, model names, prices
  with their source), and no logos.
- Comparisons with similar products, such as Magpie, state the date and the
  version they are based on, and cite sources that can be checked.
